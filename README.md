# Projeto1

Projeto desenvolvido com o objetivo de colocar em prática conhecimentos de desenvolvimento web, organização de código e construção de interfaces responsivas.

O projeto reúne conceitos de **Front-end**, estruturação de páginas, estilização e implementação de funcionalidades para proporcionar uma experiência simples, organizada e intuitiva ao usuário.

## Sobre o projeto

O **Projeto1** foi criado como parte do meu processo de aprendizado e desenvolvimento na área de tecnologia.

Durante o desenvolvimento, foram aplicados conceitos como:

* Estruturação de páginas web
* Criação de interfaces responsivas
* Organização de arquivos e componentes
* Estilização de elementos
* Interatividade com JavaScript
* Versionamento utilizando Git e GitHub

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Forterrs0/Projeto1.git
```

### 2. Entre na pasta do projeto

```bash
cd Projeto1
```

### 3. Abra o projeto

Caso seja um projeto utilizando apenas **HTML, CSS e JavaScript**, basta abrir o arquivo:

```text
index.html
```

Você também pode utilizar a extensão **Live Server** no Visual Studio Code.
